# CV Website Starter

A simple static portfolio website with a clean folder structure.

## Folder structure

```text
.
├── assets/
│   └── images/
│       └── hero-section.png
├── css/
│   └── style.css
├── js/
│   └── main.js
├── index.html
└── README.md
```

## Run locally

Open `index.html` in your browser, or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
